Motor de recomendaciones eficiente
==================================

Sistema de recomendación por filtrado colaborativo usuario-usuario
(similitud de Jaccard), desarrollado para Programación Eficiente.

Cada usuario tiene un conjunto de ítems que le gustaron. Para recomendarle,
se buscan los usuarios más parecidos (vecinos) y se le sugieren los ítems
que ellos tienen y él todavía no, priorizados por similitud acumulada.
